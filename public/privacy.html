개인정보처리방침

적용 서비스: https://webmind.danho.kr · 시행일: 2026년 10월 4일

WebMind 운영자는 마인드맵 편집, 계정 인증, 사용자가 선택한 Google Drive 저장 기능을 제공하기 위해 아래 정보를 처리합니다. Google 연결은 선택 사항이며 연결하지 않아도 브라우저에서 문서를 편집하고 내려받을 수 있습니다.

1. 처리하는 정보와 목적

정보 사용 목적과 보관 위치
이름, 이메일, 이메일 인증 상태, 계정 식별자 회원 식별과 로그인. WebMind 서버에 보관합니다. 이메일 가입 시 비밀번호는 해시로 보관합니다.
Google 계정 식별자, 이름, 이메일, 프로필 이미지 주소 Google 로그인 또는 명시적인 계정 연결에 사용합니다. Google 비밀번호를 받거나 저장하지 않습니다.
로그인 세션, 접속 IP·브라우저 정보, 보안·오류 기록 로그인 유지, 장애 진단과 오용 방지에 사용합니다. 세션 쿠키와 서버 기록으로 처리합니다.
Google 접근·갱신 토큰, 연결 이메일, 폴더·파일 ID, 문서 제목, 수정·동기화 정보 허용된 Drive 파일의 목록 표시와 저장·복구에 사용합니다. OAuth 토큰은 서버에서 암호화해 보관합니다. 파일 선택기에 필요한 단기 접근 토큰만 브라우저 메모리로 전달합니다.
마인드맵 본문, 메모, 링크, 첨부 이미지 로컬 문서·복구본은 브라우저의 IndexedDB에 저장됩니다. Drive 문서의 원본은 사용자의 Google Drive에 저장됩니다. 서버는 변환·전송 중 메모리에서 처리하며 새 Drive 문서 본문과 이미지를 영구 디스크·DB에 캐시하지 않습니다. 이전 서버 저장 방식의 원본은 별도로 보관될 수 있습니다.

2. Google Drive 권한의 사용

WebMind는 drive.file 권한으로 앱이 생성한 파일과 사용자가 Google 파일 선택기에서 허용한 파일에만 접근합니다. 해당 문서와 이미지의 읽기·저장·이름 변경·복제·휴지통 이동 및 관련 폴더 관리에 사용합니다. Google 로그인과 Drive 연결의 동의는 따로 받습니다.

Google API에서 받은 정보는 사용자가 요청한 기능 제공과 보안·장애 해결을 위해서만 사용합니다. 광고 목적의 판매·공유, 광고 타기팅, 범용 AI·머신러닝 모델 학습에는 사용하지 않습니다. WebMind의 Google API 정보 이용 및 다른 서비스로의 전달에는 Limited Use 요건을 포함한 Google API Services User Data Policy를 적용합니다.

3. 서비스를 제공하는 외부 업체

  • Google: 선택한 계정의 로그인·권한 동의, Google Drive 파일 저장 및 파일 선택기 제공.
  • Amazon Web Services: WebMind 서버와 계정 데이터 운영을 위한 호스팅.
  • Resend: 가입 인증·비밀번호 재설정 메일 전송. 수신 이메일 주소, 메일 내용 및 인증·재설정 링크를 처리합니다.

외부 업체의 처리 위치와 정책은 각 업체의 서비스 조건에 따릅니다. 사용자의 Drive 문서 내용을 이메일 발송 업체에 보내지 않습니다.

4. 보관·삭제와 연결 해제

  • 계정 정보는 계정 유지에 필요한 동안 보관합니다. 계정 및 서버에 저장된 개인정보의 열람·정정·삭제는 아래 문의처로 요청할 수 있으며 본인 확인 후 처리합니다.
  • 앱의 Drive 연결 해제는 서버의 Drive 연결 정보와 토큰과 문서 목록 캐시를 제거합니다. 회원 계정, 작업 기록, 브라우저 복구본 또는 Drive 파일까지 삭제하는 기능은 아닙니다. 서버 정보 전체 삭제를 원하면 별도로 요청하세요.
  • Google 계정의 연결된 앱 관리에서도 WebMind 권한을 철회할 수 있습니다. 이는 WebMind 회원 계정 삭제와 별개입니다.
  • Drive 문서는 앱이나 Google Drive에서 휴지통으로 이동할 수 있습니다. 최종 삭제와 복구는 Google Drive의 정책에 따릅니다.
  • 로컬 문서와 복구본은 직접 삭제하거나 브라우저의 사이트 데이터를 지울 때까지 기기에 남을 수 있습니다. 공용 기기에서는 필요한 파일을 내려받은 뒤 사이트 데이터를 삭제하세요.
  • 서버 백업에는 계정·암호화 토큰·기존 서버 문서가 포함될 수 있습니다. 삭제 요청 처리 시 백업에 남은 사본도 확인해 처리하며, 삭제한 정보를 서비스에 다시 복원하지 않습니다.

5. 보호 조치와 변경 안내

HTTPS 통신, 소유자별 접근 제어, OAuth 토큰 암호화, 서버 설정 파일의 접근 제한을 적용합니다. 비밀번호, OAuth 비밀값 및 새 Drive 문서 본문을 애플리케이션 로그에 기록하지 않습니다. 처리 목적이나 항목이 변경되면 이 페이지의 시행일과 내용을 갱신하고 필요한 동의를 받습니다.
