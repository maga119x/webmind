## 구현 범위

- React/TypeScript 편집기: 트리 편집, 다중 선택, 가지 이동·순서·좌우·계층 변경, 자유배치, 접기, 100단계 undo/redo, 검색·바꾸기, 리치 텍스트·메모·서식·아이콘·이미지·링크·화살표·구름.
- PC·모바일 조작, 한글 IME 처리, 한국어 기본/영어 전환. 상세 조작은 [MOVEMENT](MOVEMENT.md).
- FreeMind 1.0.1 `.mm` 의미 기반 입출력, 알 수 없는 XML 보존, 이미지 포함 ZIP, 텍스트·PNG·SVG·접이식 HTML·브라우저 인쇄. 정확한 시각 복제는 목표가 아니다.
- 이메일 인증·비밀번호 재설정, Google 로그인과 명시적 계정 연결, 별도 Drive 동의·Picker.

- IndexedDB 우선 기록, 2초/15초 저장, 30초 외부 확인, 충돌·오프라인 복구, 늦은 조회 응답 차단. Drive 메타데이터만 바뀌는 경우는 충돌로 보지 않는다.

## 우선 남은 일

1. 원본 보호 모드의 파일 증가 UX 개선. 원본 직접 저장은 실제 원자적 조건부 갱신 또는 동등한 데이터 보존 설계 검증 후에만 도입한다.
2. 실계정 장기 토큰 만료·철회·재연결, 이미지/ZIP 왕복, 외부 FreeMind 편집·저장 중 경쟁·응답 유실의 종합 검증.
3. 최신 동기화 수정의 Firefox/WebKit·실제 모바일 기기·실제 Safari 재검증, 실제 프린터/PDF와 FreeMind GUI 시각 검수.
4. 실제 Linux 자원 제한 하의 동시 저장·인증 부하와 장기 디스크/백업 운영. Windows 모의 부하 결과만으로 서버 여유를 보장하지 않는다.
5. 새 브라우저/여러 탭 복구 UX와 저장 요청 ID의 새로고침 후 지속성을 추가 검토한다. 현재 pending 요청 객체는 메모리에 있고 IndexedDB Draft에는 record/dirty/time만 있다.

암호화, 복제 노드, 지리 지도, 스크립트 실행, PC 파일 탐색, 실시간 협업, 공유 드라이브/타인 소유 파일, 자동 병합, 완전 오프라인 최초 실행(PWA)은 후속 범위다. 단일 Node 프로세스·단일 서버만 운영한다.
