# FreeMind 기능 대응표

기준: FreeMind 1.0.1. 원본 Java/Swing UI를 이식한 것이 아니라 `.mm` 문서와 편집 동작을 웹으로 재구현한 프로젝트입니다.

공식 참고: [기능 안내](https://freemind.sourceforge.io/wiki/index.php/Main_Page), [도움말](https://freemind.sourceforge.io/wiki/index.php/Documentation), [입출력](https://freemind.sourceforge.io/wiki/index.php/Import_and_export), [1.0 기능](https://freemind.sourceforge.io/wiki/index.php/FreeMind_1.0.0:_The_New_Features).

## 의도적인 차이

- 암호화, 복제 노드, 지리 지도, 스크립트, 실시간 협업, PC 파일 탐색은 후속 범위입니다. 암호화 파일은 거절하며 스크립트는 실행하지 않습니다.
- 임의 로컬 경로 및 외부 이미지 URL을 자동 로드하지 않습니다. 이미지 연결 후 ZIP 내보내기를 사용하면 `map.mm`과 `images/`를 함께 보관할 수 있습니다. 단독 `.mm`의 웹 첨부 URL은 로그인 없이 열 수 없습니다.
- 원본 UI 배치, 정확한 픽셀 위치, 원본 비트맵 아이콘 모양, 운영체제 글꼴 설치 여부까지 동일함을 보장하지 않습니다. 알려지지 않은 아이콘은 식별자를 보존하고 대체 기호로 표시합니다.
- 자유배치 좌표는 `.mm`의 `WEBMIND_DX`/`WEBMIND_DY` 확장 속성으로 왕복 보존합니다. FreeMind는 이 좌표를 사용하지 않으므로 동일한 시각 배치는 SVG/PNG로 내보내세요. FreeMind 원본의 HGAP/VSHIFT/VGAP은 원본 XML에 보존하지만 아직 웹 배치에 반영하지 않습니다.
- `.mm` 이외의 내보내기는 배포용 보기입니다. 편집 데이터의 장기 백업에는 `.mm`/ZIP을 사용하세요. PNG는 긴 변을 8,192px로 제한합니다.
- 브라우저 예약 단축키와 운영체제 파일 실행은 웹에 맞게 바뀝니다. PDF는 인쇄 대화상자에서 직접 저장합니다.
- 연결이 끊겨도 이미 열린 편집기에서 작업할 수 있습니다. 네트워크 없이 앱을 처음 여는 PWA 오프라인 실행은 이 버전에 포함하지 않습니다.
- Drive는 개인 계정의 본인 소유 파일만 지원합니다. 공유 드라이브·공동 편집·자동 병합은 지원하지 않습니다. 설정과 원본 보호 저장 정책은 [GOOGLE_DRIVE.md](GOOGLE_DRIVE.md)를 참고하세요.

## 호환성 수동 승인 절차

`tests/fixtures/roundtrip.mm`을 WebMind에서 열고 글자·메모·서식을 변경하여 ZIP으로 내보냅니다. 압축을 푼 뒤 FreeMind 1.0.1에서 `map.mm`을 열어 양쪽 가지·접힘·아이콘·연결선·이미지·노트와 내용을 확인합니다. 원본 실행 파일에서의 재열기는 별도 확인 항목이며 자체 파서 테스트만으로 완료 처리하지 않습니다.
