# 노드 이동과 자유배치

## 마우스와 터치

- 노드를 빈 공간으로 끌면 하위 가지와 함께 위치를 바꿉니다. 부모·순서는 유지됩니다.
- 다른 노드 가운데에 놓으면 그 노드의 자식으로 이동합니다. 위쪽·아래쪽 가장자리에 놓으면 해당 노드 앞·뒤에 삽입합니다. 드롭 표시선과 안내문으로 결과를 확인하세요.
- 중심 노드 왼쪽/오른쪽에 놓으면 해당 방향의 가지가 됩니다.
- 하단의 **자유배치**를 켜거나 Alt를 누른 채 드래그하면 다른 노드와 겹쳐도 부모가 바뀌지 않습니다.
- Shift/Ctrl/Cmd로 여러 노드를 선택하면 선택한 가지들이 함께 움직입니다. 부모와 자식을 함께 선택해도 중복 이동하지 않습니다.
- Esc로 진행 중인 드래그를 취소합니다. 완료한 이동은 실행 취소/다시 실행할 수 있습니다.
- 배경 드래그, 화면 이동 도구 또는 마우스 가운데 버튼으로 화면을 이동합니다. 모바일은 두 손가락으로 확대·축소합니다.
- 속성 → 위치와 편집에서 드래그 없이 순서·방향·부모·계층·좌표를 바꿀 수 있습니다. **선택 가지 자동배치**는 선택한 가지 전체의 자유 위치를 초기화하며 **전체 자동배치**는 문서 전체를 초기화합니다. 초기화도 실행 취소됩니다.

## 키보드

| 키 | 동작 |
|---|---|
| 방향키 | 같은 쪽 형제 또는 화면 방향의 부모/자식 선택 |
| Home | 중심 노드 선택 |
| Ctrl/Cmd + ↑/↓ | 선택한 형제의 순서 변경 (FreeMind 방식) |
| Alt + ↑/↓ | 순서 변경 대체 키 |
| Ctrl/Cmd 또는 Alt + ←/→ | 최상위 가지는 좌우 변경, 하위 가지는 중심 방향으로 한 단계 밖/바깥 방향으로 이전 형제 아래 이동 |
| Ctrl/Cmd + Shift + 방향키 | 자유 위치 10씩 이동 |
| Alt + Shift + 방향키 | 자유 위치 1씩 미세 이동 |
| Ctrl/Cmd + Z / Y | 실행 취소 / 다시 실행 |

단축키는 캔버스에 포커스가 있을 때 사용합니다. 텍스트 입력과 한글 조합 중에는 노드 조작 키를 가로채지 않습니다. 선택된 노드가 화면 밖으로 나가면 선택 이동 시 화면을 따라 움직입니다.

## 저장과 호환

자유 위치는 자동배치 기준의 상대 좌표이며 부모 가지의 이동량을 자식이 이어받습니다. 접기·펼치기, 저장·새로고침, 가지 복사, SVG/PNG 출력에 반영됩니다. 구조를 이동하면 해당 가지 최상단의 상대 위치를 초기화하여 새 부모 옆에 배치합니다.

`.mm`에는 WebMind 전용 좌표를 보존합니다. FreeMind의 자체 배치와 픽셀 단위로 일치하지 않으며 내보내기 시 안내합니다.

확인한 기존 문제: 빈 공간 드래그 무반응, Ctrl+상하가 선택만 이동, 좌측 가지 방향 탐색 오류, 다중 순서 이동 중 순서 뒤집힘, 좌측 형제 생성 방향 오류, 빠른 키보드/메뉴 조작 후 클릭이 편집으로 오인되는 경우. 이동 회귀 테스트를 추가했습니다.

참고: [FreeMind 공식 키보드 안내](https://freemind.sourceforge.io/wiki/index.php/Keyboard_shortcuts).
